# Передача работы Claude: магазин Kernora

Продолжена твоя реализация магазина из рабочего дерева и чата
`claudemakingos.txt`. Магазин включён в пакеты и Live ISO.

Текущие версии: `kernora-apps 1.1.35`, `kernora-desktop 1.4.28`,
`kernora-calamares 1.4.28`, `calamares 3.3.14-1kernora2`. Исходники находятся в `main`.
Обновление опубликовано в обычном подписанном APT-репозитории
`https://commywork9282-dotcom.github.io/kernora-updates`.

Что доработано:

- Упаковка AppStream/Flatpak, зависимости, QML-модуль, переводы,
  Flathub remote и получение Debian DEP-11 иконок.
- Поиск при переходе со страницы приложения, категории и список
  установленных приложений, включая приложения вне магазина.
- Отмена фоновых задач и корректное завершение рабочего потока.
- Проверка обновлений с отображением ошибок и повторной попыткой;
  сохранение последнего списка при сетевой ошибке.
- Проверка ошибок PackageKit и локальных файлов, корректное состояние
  приложений после операций. Обновления Flatpak — в магазине,
  обновления системы и Debian — в настройках.
- Значок вместо недоступного снимка экрана и честная подсказка об
  обновлениях Flatpak. Новый магазин закреплён для новых профилей.
- What's New на русском и английском; необязательное поле `date`
  отделяет отображаемую дату от стабильного ID записи.

Проверено: `make verify`, сборка и проверки бинарных пакетов,
`tests/test-live-rootfs.sh`. В отдельной QEMU-сессии проверены установка,
запуск и удаление galculator (Debian) и GNOME Calculator (Flathub).

1119 игр, список установленных приложений, пустой поиск и детали Telegram.
Проверены переход к новому поиску без Enter и окно «Что нового».
Логи и снимки экрана: `out/test-logs/store/`.

Дополнение от 12 октября: `kernora-apps 1.1.31` исправляет выбор запускаемой
установки. Flatpak запускается по точному scope/ref, с метаданными его
экспортированного ярлыка; Debian использует свои AppStream launchables.
Ошибки запуска выводятся пользователю. Добавлены What's New и регрессия
`tests/store-launch-smoke/`: на 1.1.30 воспроизведён запуск неправильного
нативного ярлыка при установленном Flatpak.

Это отдельная найденная ошибка, а не подтверждённая причина жалобы на CS2.
Отчёт: `docs/STEAM_MOUSE.md`. На двух экранах QEMU базовый захват SDL2
удержал фокус; CS2 и реальная конфигурация игрока не проверены. Не объявляй
проблему ухода курсора из CS2 исправленной на основании этого выпуска.
Комментарии в новый код не добавлять — просьба пользователя в `AGENTS.md`.

Проверка финального 1.1.31 в QEMU прошла: правильные scope/ref,
сохранены `--command=Telegram` и file forwarding; SHA256 экспортированного
ярлыка до и после совпадает. Реальный Flatpak принял полный ref.
`make verify`, сборка и проверка бинарного пакета, проверка локального
архива прошли. Новый ISO для этого исправления не собирался; пакет
поступает через существующий канал обновлений. Следующая версия выше 1.1.31.

Зависание любой установки на 99% проверено отдельно. На хосте оставалось
426 МБ, libvirt дважды поставила `vm1` на паузу из-за I/O error; внутри
гостя было 9,1 ГБ свободно. Копия диска с отдельным overlay на HDD успешно
завершила установки Debian galculator и Flatpak GNOME Calculator (790 МБ
загрузок), включая этап 99%, с исходным магазином 1.1.30. Исходный диск
пользователя и конфигурация VM не менялись. Отчёт: `docs/VM_INSTALLATION.md`.

Для устранения причины освобождено место SSD: общедоступные установочные
ISO Windows и Xubuntu перенесены на `/mnt/hdd2tb/ISO-archives`, контрольные
суммы проверены, старые пути сохранены ссылками. На SSD теперь около 13 ГБ
свободно. Сборочный `_cache`, `downloads` и временные результаты сборки
тоже находятся на HDD, ссылки сохраняют рабочие пути. `.gitignore`
учитывает ссылки на эти каталоги. Секретные ключи не переносились.

Не выпускать новый тег/релиз из-за этого случая: обновляется существующий
`v1-ember-5`. Не объявлять исправление кода установщика — причина в
хранилище хоста. Регрессия установки: `tests/store-install-smoke/`.

Повторный проход тоже успешен: 21 проверка QMP вернула `running`, паузы
из-за I/O не было. Максимальный интервал Qt-таймера 2,129 с относится к
